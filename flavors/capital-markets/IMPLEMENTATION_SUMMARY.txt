================================================================================
ARCHITECTURE PATTERNS
================================================================================

All agents implement the PRREEL Loop:
1. PERCEIVE - Parse and validate input data
2. RETRIEVE - Get relevant context from memory systems
3. REASON - Use LLM with rule-based fallback logic
4. EXECUTE - Perform core operations
5. VERIFY - Validate results and check completion
6. LEARN - Store outcomes in memory for future improvement

Memory Integration:
- Procedural Memory: Successful strategies and patterns
- Episodic Memory: Historical decisions and interactions
- Semantic Memory: Rules, guidelines, and intelligence

Policy Integration:
- Pre-execution policy checks via policy_engine
- Graceful fallback when policy engine unavailable

Error Handling:
- Comprehensive try/except blocks with logging
- Confidence scoring reflects decision uncertainty
- Fallback strategies for all LLM-dependent decisions

Observability:
- Structured logging with structlog
- OpenTelemetry span tracking (when enabled)
- Latency and success metrics
